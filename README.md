# Password Strength Checker

A simple Python program that checks how strong a password is.

## Features
- Checks password length (minimum 8 characters)
- Checks for uppercase and lowercase letters
- Checks for numbers and special characters
- Gives a rating (Weak, Medium, Good, Strong) and tips to improve

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `python password_checker.py`
4. Enter a password when asked.

## Example Output
Strength: Medium
 - Add a number.
 - Add a special character.
